# Browser Profile Setup for Wallet Development

## Why Use Browser Profiles?

When developing blockchain applications, you often need different wallets for different chains (Ethereum, Aptos, Solana, etc.). Having all extensions active causes conflicts.

## Solution: Create Separate Browser Profiles

### Create a Profile for Aptos Development

1. **Open Chrome Menu** → Click your profile icon (top right)
2. **Click "Add"** → Select "Add profile"
3. **Name it**: "Aptos Development" or "Movement Network"
4. **Choose a color/icon** to easily identify it

### Install Only Aptos Wallets in This Profile

In your new "Aptos Development" profile:

1. **Install ONLY ONE of these**:
   - [Petra Wallet](https://chrome.google.com/webstore/detail/petra-aptos-wallet/ejjladinnckdgjemekebdpeokbikhfci) ✅ Recommended
   - OR [Martian Wallet](https://chrome.google.com/webstore/detail/martian-wallet/efbglgofoippbgcjepnhiblaibcnclgk)
   - OR [Pontem Wallet](https://chrome.google.com/webstore/detail/pontem-aptos-wallet/phkbamefinggmakgklpkljjmgibohnba)

2. **DO NOT install**: MetaMask, Razor, Nightly, Backpack, or any other Ethereum wallets

### Switch Between Profiles

- Click your profile icon in Chrome
- Select "Aptos Development" when working on this project
- Select your default profile for other work

## Benefits

✅ No wallet extension conflicts  
✅ Faster page loads (fewer extensions)  
✅ Cleaner development environment  
✅ Can still use Ethereum wallets in your default profile  
✅ Separate bookmarks, history, and settings per profile

## Quick Profile Switching

**Keyboard Shortcuts**:
- Windows/Linux: `Ctrl + Shift + M` to manage profiles
- Mac: `Cmd + Shift + M` to manage profiles
